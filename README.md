# Netflix_1099

📊 Netflix Titles Dashboard Project
🔍 Overview
This project analyzes Netflix's title catalog using Python (Pandas) and Power BI to explore trends across genres, release years, production countries, and more. The goal is to demonstrate data cleaning, visualization, and dashboarding skills for a data analyst or BI developer role.

💾 Dataset
Source: Netflix Titles Dataset on Kaggle

netflix_titles.csv: Raw dataset of Netflix titles

netflix_cleaned.csv: Cleaned version used for Power BI

🧹 Data Cleaning (Python)
Performed in netflix_cleaning.ipynb:

Removed null/missing values

Parsed genre and date columns

Standardized boolean fields

Cleaned noisy categories (e.g. "['Comedies', 'International']")
